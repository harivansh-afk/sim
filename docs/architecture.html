sim architecture: the HTML path

This page tests the HTML adapter. Open it with sim docs/architecture.html: it converts once through rehype-parse and rehype-remark into the same block model the markdown adapter produces, then renders identically.

HTML documents are readonly by construction: the adapter omits serialize, so writeback is false and the status bar shows a readonly badge. Try x on the list below: sim refuses politely.

Code blocks

// the adapter, in essence
const markdown = String(htmlToMd.processSync(fileText));
return { root: parseMarkdown(markdown), text: markdown, writeback: false };

Why one-way

No source positions map back to the original HTML after conversion, so a positional splice into the .html file is impossible. Rather than guess with a lossy serializer, sim keeps the file untouchable. The day HTML needs editing, that is a new adapter contract, not a patch.
